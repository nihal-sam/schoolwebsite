# 🌟 VN Kindergarten School Website

A static, responsive educational website designed for a kindergarten school. This project showcases a visually appealing, child-friendly layout ideal for institutions aiming to highlight their facilities, staff, and programs.

## 📌 Live Demo

🔗 [Visit the Live Site](https://vnkindergardenschool.netlify.app/)

## 📂 Project Overview

This project was created as a frontend showcase for a kindergarten school. The layout is clean, vibrant, and informative — built using pure HTML, CSS, Bootstrap, and JavaScript. It includes multiple sections such as:

- Hero Banner
- About the School
- Programs Offered
- Teachers Introduction
- Gallery
- Contact and Footer

## 🔧 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Bootstrap 4**
- - **SQL**
- **AOS (Animate On Scroll) Library**
- **Netlify** (for static deployment)
